# Трекер домашних заданий MVP

## Пользователь
Студент, которому нужно следить за домашними заданиями и сроками сдачи.

## Проблема
Задания записаны в разных местах, поэтому про них легко забыть и пропустить дедлайн.

## Гипотеза
Если собирать все задания и даты сдачи в одном простом списке, студент будет сдавать работы вовремя.
